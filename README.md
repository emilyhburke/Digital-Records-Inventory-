# Digital-Records-Inventory-
 Synthetic Data with refrence to Ontario Open Data Portal
 To view Databse, navigate to the file: **File_Inventory_Project**

## Objective

This project simulates an information management workflow using synthetic records, with Ontario Open Data Portal conventions used to inform naming, version control, and dataset structure. The data was selected to mirror realistic, publicly available resources.

The purpose was to clean a network drive in preparation for SharePoint Online migration. I built a file inventory to manage records, classified retention and disposition cases, and identified unreferenced and duplicate files using structures associated with public-sector operations.

## Guidelines & Resources

This project required understanding standard government record management principles and guidelines, standardized data privacy and access, and publicly available software parallel to government use-cases.

### Records & Information Management (IM)

- **ISO 15489**: Public-sector, international standards for records management
- **Government of Ontario**: Government record theory
- **Ontario Open Data Portal**: Datasets, metadata
- **Library and Archives Canada**: Disposition, records management
- **Microsoft Learn documentation** (Excel)
- **Microsoft SharePoint documentation** (lists, metadata, migration)

### Data Privacy & Access

- **IPC Ontario**: Privacy and access documentation
- **Ontario FIPPA/MFIPPA**: Comprehension

### Software and Data Structures

- Excel Tables
- Excel Data Validation Tools
- SharePoint-style inventories
